Deploy

Your factory, in your Cloudflare account.

Three steps, a few minutes. Everything runs in your account, on your domain.

  1. Turn on R2

    The factory keeps runner releases and files in R2, Cloudflare’s object storage. It has to be switched on once per account before anything can use it. It’s free to start, though Cloudflare asks for a payment method.

    Open R2 in Cloudflare →

    Already using R2 in this account? You’re set.

  2. Deploy

    Cloudflare copies the factory into a repo of yours, creates its database, storage and Durable Objects, and asks for your GitHub organization (or your username, for a factory just for you).

    Deploy to Cloudflare

  3. Finish at /setup

    Open https://<your factory>/setup as an owner of the GitHub organization (or as yourself). GitHub creates the factory’s app, your team signs in, and you add machines from the Mac app.

Rather use the terminal? npx maple-factory install does all three, turns R2 on with you if it isn’t, and keeps the factory on signed stable or beta releases.

Add a Linux server with cloud-init

Making a droplet or VM for the factory? Paste the factory’s cloud-init snippet as its user-data and the box comes up already in the factory: a maple user with git, tmux, Node LTS and the agent CLIs, lingering on, and the runner running as maple’s service. Get it from the Mac app under Machines → Add machine → Linux server (cloud-init), with your code filled in, or fetch it yourself:

curl https://<your factory>/cloud-init.yaml?code=XXXX-XXXX

It works as user-data on DigitalOcean, Hetzner, AWS, Multipass and anywhere else that runs cloud-init on Ubuntu or Debian. Trimmed, it looks like this:

#cloud-config
users:
  - default
  - name: maple
    shell: /bin/bash
packages: [git, tmux, curl, ca-certificates]
runcmd:
  - |
    curl -fsSL https://deb.nodesource.com/setup_lts.x | bash -
    apt-get install -y nodejs
    npm install -g @anthropic-ai/claude-code @openai/codex
    loginctl enable-linger maple
    sudo -iu maple sh -c 'curl -fsSL https://<your factory>/install.sh | sh -s -- XXXX-XXXX'

The code works once and runs out 15 minutes after it was made, so create the box right away; the app shows when yours runs out. Agents still sign in by hand: ssh maple@<host> and run claude (then /login); Codex signs in from the machine’s page in the app, or with codex login --device-auth.
