How it works

Four steps. You only show up for two.

Approve the plan before any code is written. Approve the merge once it’s proven. Everything in between runs without you.

  1. 01

    Tap · Plan

    Agree on the plan first.

    A planner reads the repo and writes up what it’ll change, with mockups for anything visual. Approve it, question it or send it back. No code until you say so.

    ## Plan · MF-142
1. exportCSV() on reports
2. Stream rows, no buffer
3. Toolbar button
4. Test 100k rows
  2. 02

    Boil · Build

    Built on a machine you own.

    A runner on one of your team’s Macs picks it up, in a session that survives sleep, network blips and updates. It runs on the owner’s Claude Code or Codex plan, inside the limits they set.

    studio-mac · session 3
✓ 12 files changed
✓ tests 214 passed
→ pushed mf-142
  3. 03

    Grade · Review

    Checked by someone who didn’t write it.

    A separate reviewer reads the diff while CI runs and the task gathers proof: screenshots, recordings, test output. It all lands on one page.

    review · 2 notes, fixed
checks · 14 / 14
proof  · export.mov
  4. 04

    Bottle · Merge

    Merged when you say.

    Approve from your desk or your phone. Maple Factory opens the pull request, waits for green checks and squash-merges it.

    ● Merged #388
  into main
  approved by AF

The details

The parts that usually break, handled.

Sessions don’t vanish

When a session ends, you’ll know why. Sleep, a dropped connection or an update picks up from the last checkpoint. A crash, an expired login or a usage limit stops and asks for help, with the last screen attached.

Built for a team, not a laptop

Sign in with your GitHub org, and its teams decide who can do what. Share machines, hand off tasks, and pause your own runner without stranding someone else’s work.

Lives in your Cloudflare account

One deploy per org, in your account: Workers, Durable Objects, D1 and R2. Your code, sessions and terminals stay in your account.

Review from your phone

Plans, mockups, diffs, reviews and checks, all in the browser. Approve, push back, merge or answer an agent’s question from wherever you are.

Tailscale, built in

Open a branch’s running app, share a port or send a teammate a preview link, all over your own tailnet.

No new AI bill

Everyone uses the Claude Code or Codex login they already have. Planners and reviewers do too, so the whole factory follows your team’s model choices.

Install

Up and running in one command.

maple install sets up everything in your Cloudflare account, signs you in with GitHub and enrolls the Mac you’re on. Add your teammates’ machines whenever you’re ready.

  • Nothing to host or patch
  • Runners connect out, so there’s no firewall to open
  • Signed updates on a stable or beta channel
