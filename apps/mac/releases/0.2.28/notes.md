### Added

- **Recurring tasks**: a goal can start a task from a saved prompt every few hours, days or weeks. Open **Recurring** on a goal and choose **Add Recurring Task**. You can pause one, run it now or delete it.

### Changed

- Proof screenshots and recordings arrive at full size and show large.
- **What's New in the Runner** looks and works like the app's own update notes.
- Agents' avatars are a robot face, colored by role: planner, builder or reviewer.
- Signing in shows GitHub's device code large, with a **Copy** button.

### Fixed

- Renaming a goal in **Edit Goal…** keeps you on that goal instead of jumping to the first one.
