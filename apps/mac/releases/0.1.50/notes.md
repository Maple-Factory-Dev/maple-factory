### Added

- **A review suite on the Diffs tab:** a file tree beside the code, which no longer wraps, and the tab takes the whole window. Comment on lines into a pending review and send it as one change request; each note is posted on the pull request at its line. The pull request's own review threads show inline.
- The timeline shows review comments with their file, lines and code.
