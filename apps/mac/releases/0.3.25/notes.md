### Added

- Empty Inbox, **My tasks**, **Needs a hand** and task lists now say what will show up there and how to get started, instead of showing a blank pane. A filtered list with no matches offers **Clear filter**.
- Connect Claude, Cursor or another MCP client to your factory's docs: it can read docs, comment, suggest edits and propose decisions as you, with a "via MCP" badge. Set it up in the web app's Settings.

### Fixed

- The collapsed sidebar no longer shows made-up usage figures on a live factory.
