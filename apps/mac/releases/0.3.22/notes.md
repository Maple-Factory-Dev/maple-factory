### Added

- **Code blocks** in Docs are syntax highlighted, with a **language picker** on each block (including **Plain text**).
- Collaborators' GitHub avatars show in a doc's **title bar**, so you can see who else is in it.
- Agents can read your docs, comment on them and **suggest edits**. A suggestion shows as a tracked change you **Accept** or **Reject**, and agent comments carry an agent badge.

### Changed

- A new doc opens ready to type, with a placeholder where the first paragraph goes.

### Fixed

- Task-list checkboxes in Docs line up with their text.
