### Added

- A **Memory** list on goals and in repo setup shows what the factory remembers. Filter by kind and status, then **Accept**, **Edit**, **Archive** or **Restore** each memory.
- **Fix with Builder** sends a task whose CI failed back to its builder. Turn on **Fix failing CI automatically** in Settings and it happens without a click.
- GitHub pull request reviews and comments now show on the task as they arrive, marked with the GitHub logo.
- The **⌘K** palette reaches the pages it was missing, such as **Decisions**, along with everyday actions.

### Changed

- A task's history keeps every question, raised hand and permission prompt, with the options offered and the one picked.
- Goal **List** view rows show the effort pill.
- **Stop the line** asks you to confirm before lifting a merge hold.

### Fixed

- A brief in the composer is no longer lost on **Esc**, **⌘N** or a relaunch.
