### Added

- **Agent and model on a task:** the task inspector shows which agent and model will build it, with menus to change them. A change applies from the task's next session.
- **Factory name:** admins name the factory in Settings › Appearance (like "Andrea's Factory"), and it shows in the sidebar instead of the GitHub org. **Use Org Name** goes back.

### Changed

- New Task always puts the cursor in the title, even when the composer is already open.
