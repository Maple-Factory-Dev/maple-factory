### Added

- **Runner updates you can follow:** each machine's card shows its runner update as it happens (checking, installing, restarting, updated) and, if one fails, why, with **Show Log** and **Retry**.
- **What's New for runners:** see what changed in the runner releases since the one a machine has, from its card or Settings › Runner.
- **Task references:** type **#** in the editor or a comment to pick a task. Task IDs you mention link to the task and open it.

### Changed

- A machine that's restarting into a new runner reads **Restarting**, not Offline.
- Settings › Runner holds its Update button while an update runs.
