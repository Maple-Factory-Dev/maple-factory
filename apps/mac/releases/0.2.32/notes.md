### Changed

- **Assign…** opens a searchable list of people, instead of a nested **Assign to ▸** menu.
- A plan shows its current steps. A revision's changes show by default only while it waits for approval.
- Each Settings pane's header has room below the title bar.
- Comes with runner 0.91.0, which can stream a session as native events for the upcoming native session view.
